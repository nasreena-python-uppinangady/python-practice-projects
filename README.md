## 📁 Projects

### 1. Expense Tracker (`expense_tracker.py`)
A personal finance tool to track daily expenses.

**Features:**
- Add new expenses with amount, category and notes
- View all expenses with total spent
- View total spending by category (Food, Travel, Shopping etc.)

**Skills Used:** Python Basics, Lists, Dictionaries, Loops, Functions

### 2. Student Grade Management System (`student_grade_system.py`)
A simple system to manage student marks and grades.

**Features:**
- Add students with 3 subject marks
- View all students with average and grade (A+, A, B, C, F)
- Find the class topper

**Skills Used:** Python Functions, Dictionaries, Conditional Logic

## 💻 How to Run
1. Install Python on your computer
2. Download the files
3. Run: `python expense_tracker.py` or `python student_grade_system.py`
